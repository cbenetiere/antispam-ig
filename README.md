# Antispam Instagram

Masque (sans jamais supprimer) les commentaires de bots : caractères invisibles ou sites de spam connus.
Aucune IA. Les identifiants sont des secrets GitHub ; les journaux ne contiennent que des totaux.

- `passer.py` : un passage (lit les dernières publications, masque le spam)
- `.github/workflows/antispam.yml` : lancé toutes les 10 minutes
